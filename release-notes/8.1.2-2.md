## Common

- Keep the QSV decoder frame pool when the stream parameters change, so older Intel devices (Gen9-Gen11) can continue to encode after a mid-stream SPS change.

## Native

- Windows: find legacy Intel Media SDK runtimes (for example API 1.20 on Haswell) when the Intel GPU is not the primary display adapter, and report the adapter's device ID when an old runtime does not, so QSV can use these devices
- Windows: fix QSV video processing (`vpp_qsv`, `overlay_qsv`) of uploaded or already processed frames on legacy Intel Media SDK runtimes, which failed with "device failed (-17)"
