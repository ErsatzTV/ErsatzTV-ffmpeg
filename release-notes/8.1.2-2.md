## Common

- QSV decode: keep the frame pool when stream parameters change but the resolution does not. This fixes encode after a mid-stream SPS change on runtimes with a fixed pool (legacy Intel Media SDK, or D3D9). A resolution change still fails on these runtimes.

## Native

- Windows: QSV can use a legacy Intel Media SDK runtime when the Intel GPU is not the primary display adapter, or when the runtime does not report a device ID.
- Windows: fix `vpp_qsv` and `overlay_qsv` on frames from `hwupload` or from another QSV filter. On legacy Media SDK runtimes, this failed with "device failed (-17)".
- Windows: `hwupload` and `hwdownload` of QSV frames now copy through D3D11 on all runtimes. On legacy Media SDK runtimes, this fixes "Error synchronizing the operation: -17" at the start of a stream.
