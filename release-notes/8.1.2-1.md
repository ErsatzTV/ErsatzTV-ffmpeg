First immutable release using a new revision scheme: `8.1.2-N`, for docker builds and native builds.

## Common

- Use `etv.N` version suffix (`8.1.2-etv.1`, native `n8.1.2-etv.1`) instead of a build date or a commit hash
- Use same ffmpeg patch set for docker builds and native builds

## Docker

- Remove `libfdk_aac` and `--enable-nonfree` from all docker images; the built-in `aac` encoder is still present
- Remove the `linux/arm/v7` image; once `:8.1.2` and `:latest` are promoted to this release they no longer resolve on `linux/arm/v7`. The last `linux/arm/v7` build is `ghcr.io/ersatztv/ersatztv-ffmpeg:8.1.2@sha256:effcdf7b69c425f84e338c05cbf51807ac302651b70cac603b115c6cca2ab2e2`

## Native

- Dependencies rebuilt from current upstream FFmpeg-Builds; `librsvg` (SVG decoding) is now enabled
