First release under the revision scheme: `8.1.2-N` tags are immutable and are never re-uploaded. A new build is a new revision. See the README for how floating tags, pinning and verification work.

Changes from the previous `8.1.2` docker image:

- One patch set for docker and native. Docker gains the vaapi_encode surface alignment, both d3d11va, amfdec mpeg2/vc1 and liboapvenc patches.
- `libfdk_aac` and `--enable-nonfree` are removed from all docker images: a nonfree build is not redistributable. The built-in `aac` encoder remains.
- The version suffix is `etv.1` instead of a build date or commit hash.
