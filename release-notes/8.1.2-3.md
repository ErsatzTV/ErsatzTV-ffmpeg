First release with native macOS builds.

## Docker

- Build without `--enable-small`. `ffprobe` reports codec long names and profile names again (for example `High` instead of `100`)

## Native

- macOS: new `macos64` (Intel) and `macosarm64` (Apple silicon) builds for macOS 15 or newer, signed and notarized by Apple
- Linux and Windows: remove `ffplay` and SDL2; each archive now has only `ffmpeg` and `ffprobe`
