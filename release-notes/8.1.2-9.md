## Common

- Fix a box appearing next to Arabic lam-alef ligatures (such as in بلا) in burned-in text subtitles when the font has no U+FEFF glyph (e.g. Arial)
  - This is a backport of an upstream FFmpeg 9.0 change: the `subtitles` filter gets a `shaping` option and now defaults to complex (HarfBuzz) shaping, like the `ass` filter
