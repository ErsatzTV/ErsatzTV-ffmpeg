## Common

- Fix MPEG-2 decoding attaching the closed captions of skipped pictures to the first decoded frame
  - This fixes `h264_vaapi` failing with "Access unit too large" when a stream with captions starts mid-GOP
- QSV: fix late frames after a seek, caused by negative timestamps
- QSV: fix every frame being late in some MPEG-2 streams that start on an open GOP
- QSV: drop the corrupted leading frames before the first keyframe of an H.264 stream that starts on an open GOP
- QSV: fix VC-1 decoding of ASF/WMV sources ("image parameters invalid" for every frame)

## Native

- AMF: drop the corrupted leading frames before the first keyframe of H.264, HEVC and MPEG-2 streams
- AMF: fix AV1 decoding of HDR10 streams ("File exists" error when the container also has HDR metadata)
- AMF: fix AV1 decoding of 10-bit streams when the format is only known after the first frame
- AMF: fix `hevc_metadata` and other HEVC bitstream filters failing on `hevc_amf` output
- AMF: remove the `vc1_amf` decoder
  - It played VC-1 from MKV with judder. `-hwaccel amf` uses software VC-1 decoding again
